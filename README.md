# Decentralized AI Compliance Simulation

This example simulates a decentralized AI collective attempting to perform various tasks while adhering to geopolitical compliance rules. It demonstrates how "sanctions" can restrict which AI nodes are allowed to execute specific tasks based on their origin, capabilities, and target regions. This highlights the challenges of managing AI operations across international boundaries and the concept of compliance in a decentralized system.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal using `python main.py`.
